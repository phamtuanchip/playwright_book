# Automation Testing With Playwright: A Free Vietnamese Book From QA Basics to AI and MCP

*30 chapters and 3 appendices, going from "what is QA?" to self-healing tests and AI agents that drive the browser.*

Playwright is quickly becoming the default choice for end-to-end testing, but learning it well means understanding testing itself, not just the API. This book covers both: **QA fundamentals first, then Playwright basics, advanced features, and finally AI with MCP.** It assumes basic JavaScript. **It is written in Vietnamese today; an English edition is planned.**

## Who it is for

- Manual testers moving into automation
- Developers who want to write reliable end-to-end tests
- QA engineers curious about using AI in their test workflow

## What is inside

- **Part I — QA in the SDLC:** where testing fits, manual vs automation, unit/integration/E2E/regression, test cases, plans and bug reports
- **Part II — QA roles:** product, functional and technical QA; when to automate and when not to; the mindset of an automation engineer
- **Part III — Setup:** Node.js, package managers, VS Code, project structure, and a demo app used throughout the book
- **Part IV — Playwright basics:** architecture and comparison with Selenium/Cypress, locators, actions and assertions, hooks, forms and file upload, auto-waiting and network, Page Object Model, fixtures, debugging with Trace Viewer, UI mode and codegen, reporting
- **Part V — Advanced Playwright:** API testing, visual comparison, authentication and storage state, parallelism and sharding, cross-browser and mobile emulation, component testing, custom fixtures and reporters
- **Part VI — AI and MCP:** what the Model Context Protocol is, the Playwright MCP server, AI-generated test cases, self-healing tests, and a semi-automated pipeline case study
- **Appendices:** best practices checklist, troubleshooting, references

A single demo application is used across chapters, so each technique builds on the last. The repository includes runnable Playwright projects.
