# Ví dụ Chương 3 — Test Plan & Bug Report

Hai artifact QA thật, viết cho cùng tính năng "Đăng nhập" đã dùng xuyên suốt Chương 1–2, để bạn
thấy toàn bộ chuỗi tài liệu QA khớp với nhau: **Test Plan** (kế hoạch, phạm vi) → **Test Case**
(đã có ở `code/ch01-sdlc/test-case-list-login.md`) → **Bug Report** (khi một test case fail).

- [`test-plan-login.md`](./test-plan-login.md) — test plan cho tính năng đăng nhập.
- [`bug-report-example.md`](./bug-report-example.md) — bug report mẫu, viết ra từ việc chạy
  TC-07 (khoá tài khoản sau 5 lần đăng nhập sai) trong bộ test case Chương 1 và phát hiện lỗi.
